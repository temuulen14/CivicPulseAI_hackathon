# Frontend · CuentasClaras

React + Vite + Recharts, en JavaScript y CSS normales.

```bash
cd frontend
npm install
npm run dev        # http://localhost:5173
```

- Sin backend: deja `VITE_API_URL` vacía y la app usa los datos de ejemplo (`src/mocks.js`).
- Con backend: crea `frontend/.env.local` con `VITE_API_URL=http://localhost:8000/api`.

Registro de cambios explicado, paso a paso: [`CAMBIOS.md`](CAMBIOS.md).
